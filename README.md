# ♡ StudyList - Aplikasi Daftar Tugas Kuliah

## 🌷 Tentang Proyek

StudyList adalah aplikasi daftar tugas kuliah berbasis web sederhana yang dibuat untuk membantu mahasiswa mencatat, mengatur, dan mengingat deadline tugas perkuliahan.

Dengan StudyList, mahasiswa dapat mengelola tugas kuliah dengan lebih mudah dan teratur.

## ✨ Fitur Utama

1. Menambahkan tugas kuliah.
2. Mengedit informasi tugas.
3. Menghapus tugas.
4. Menandai tugas yang sudah selesai.
5. Melihat jumlah total tugas.
6. Melihat jumlah tugas yang sudah dan belum selesai.
7. Mencari tugas berdasarkan nama tugas atau mata kuliah.
8. Menyimpan data menggunakan LocalStorage.

## 💻 Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- LocalStorage

## 🚀 Cara Menjalankan Website

1. Download atau clone repository StudyList.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka file `index.html` menggunakan browser.
4. Website StudyList siap digunakan.

## 📌 Tujuan Pembuatan

Website ini dibuat untuk membantu mahasiswa mengelola tugas perkuliahan agar lebih terorganisir, mengurangi risiko lupa deadline, dan meningkatkan semangat belajar.
