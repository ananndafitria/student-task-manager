# Aplikasi Daftar Tugas Kuliah

## Tentang Proyek

Aplikasi Daftar Tugas Kuliah adalah website sederhana
yang dibuat untuk membantu mahasiswa mengatur dan
mencatat tugas perkuliahan.

## Fitur Utama

1. Menambahkan tugas kuliah.
2. Mengedit tugas.
3. Menghapus tugas.
4. Menandai tugas yang sudah selesai.
5. Menampilkan jumlah tugas.
6. Menyimpan data menggunakan LocalStorage.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- LocalStorage

## Cara Menjalankan

1. Download atau clone repository ini.
2. Buka folder proyek menggunakan VS Code.
3. Buka file index.html melalui browser.
4. Website siap digunakan.
